# Документация проекта Geometric Lib

## Общее описание решения

Проект представляет собой модульную библиотеку на языке Python 3, содержащую функции для вычисления геометрических параметров базовых плоских фигур: круга, квадрата, прямоугольника и треугольника.

Логика разбита по отдельным файлам под каждую фигуру. Все функции сопровождаются аннотациями параметров, возвращаемых типов и практическими примерами использования.

---

## Описание функций

### 1. Модуль circle.py

#### area(r)

Вычисляет площадь круга по заданному радиусу.

- Параметры:
  - `r` (`float` | `int`): радиус круга.
- Возвращаемое значение:
  - `float`: площадь круга.
- Пример вызова:

```python
import circle

res = circle.area(5)
print(res)  # 78.53981633974483
```

#### perimeter(r)

Вычисляет длину окружности (периметр круга) по радиусу.

- Параметры:
  - `r` (`float` | `int`): радиус круга.
- Возвращаемое значение:
  - `float`: длина окружности.
- Пример вызова:

```python
import circle

res = circle.perimeter(5)
print(res)  # 31.41592653589793
```

### 3. Модуль rectangle.py

#### area(a, b)

Вычисляет площадь прямоугольника по двум смежным сторонам.

- Параметры:
  - `a` (`float` | `int`): первая сторона.
  - `b` (`float` | `int`): вторая сторона.
- Возвращаемое значение:
  - `float` | `int`: площадь прямоугольника.
- Пример вызова:

```python
import rectangle

res = rectangle.area(3, 5)
print(res)  # 15
```

#### perimeter(a, b)

Вычисляет периметр прямоугольника.

- Параметры:
  - `a` (`float` | `int`): первая сторона.
  - `b` (`float` | `int`): вторая сторона.
- Возвращаемое значение:
  - `float` | `int`: периметр прямоугольника.
- Пример вызова:

```python
import rectangle

res = rectangle.perimeter(3, 5)
print(res)  # 16
```

---

### 4. Модуль triangle.py

#### area(a, h)

Вычисляет площадь треугольника по основанию и высоте.

- Параметры:
  - `a` (`float` | `int`): длина основания.
  - `h` (`float` | `int`): высота, проведенная к этому основанию.
- Возвращаемое значение:
  - `float`: площадь треугольника.
- Пример вызова:

```python
import triangle

res = triangle.area(6, 4)
print(res)  # 12.0
```

#### perimeter(a, b, c)

Вычисляет периметр треугольника по трем сторонам.

- Параметры:
  - `a` (`float` | `int`): первая сторона.
  - `b` (`float` | `int`): вторая сторона.
  - `c` (`float` | `int`): третья сторона.
- Возвращаемое значение:
  - `float` | `int`: периметр треугольника.
- Пример вызова:

```python
import triangle

res = triangle.perimeter(3, 4, 5)
print(res)  # 12
```

## Формулы

| Фигура        | Площадь                   | Периметр        |
| :------------ | :------------------------ | :-------------- |
| Круг          | $S = \pi r^2$             | $P = 2 \pi r$   |
| Квадрат       | $S = a^2$                 | $P = 4a$        |
| Прямоугольник | $S = a \cdot b$           | $P = 2(a + b)$  |
| Треугольник   | $S = \frac{a \cdot h}{2}$ | $P = a + b + c$ |
