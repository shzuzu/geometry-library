# Geometric Lib

Учебная библиотека на Python для вычисления параметров геометрических фигур (площадь и периметр). Проект подготовлен в рамках лабораторной работы по документированию исходного кода и оформлению Markdown-документации.

## Состав проекта

- `circle.py` — расчеты для круга
- `square.py` — расчеты для квадрата
- `triangle.py` — расчеты для треугольника
- `docs/` — каталог с полной документацией проекта

## Пример работы

```python
import circle
import square

print(circle.area(5))          # 78.53981633974483
print(square.perimeter(5))  # 20
```
